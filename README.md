# Student Information Dictionary

## Internship Details
- **Organization:** Veda Technology
- **Task:** Task 7
- **Project:** Student Information Dictionary
- **Domain:** AI & ML
- **Language:** Python

## Project Description
This project uses a Python dictionary to store student information. It demonstrates how to search for student records, add new students, and update existing student details.

## Objectives
- Understand Python dictionaries and key-value pairs.
- Store student records using unique student IDs.
- Search for student information.
- Add new student records.
- Update existing student records.

## Technologies Used
- Python
- Google Colab / Jupyter Notebook

## Features
1. Display all student records.
2. Search for a student by ID.
3. Add a new student.
4. Update student marks.
5. Display the updated records.

## How to Run
1. Download `Student_Information_Dictionary.ipynb` from this repository.
2. Open it using Google Colab or Jupyter Notebook.
3. Run the code cells to view the results.
